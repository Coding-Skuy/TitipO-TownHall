# SRS Functional Requirements

TitipO mengelola order harian rumah tangga ↔ vendor terpercaya dengan fee 12% dan repeat-order ≥40%.

## Functional Requirements

- SRS-FR-001: Fungsi inti harus punya test merah-hijau sebelum implementasi.
- SRS-FR-002: Setiap error path punya test eksplisit.
- SRS-FR-003: Use case harus teridentifikasi dan testable per acceptance criteria.

## Batasan

Functional requirements tidak menentukan algoritma internal; hanya behavior yang observable.
